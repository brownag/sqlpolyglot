# AGENTS.md - sqlpolyglot

## Project Overview
`sqlpolyglot` is an R package that exposes a Rust SQL transpiler (`polyglot-sql` crate) to R via extendr (rextendr 0.5.0). R functions wrap Rust functions; the Rust crate is compiled into a static library and linked into the R shared object during `R CMD INSTALL`.

## Core Commands
Run from the repository root.

* **Install deps**: Rust toolchain (`cargo`, `rustc` >= 1.65 per `SystemRequirements` in `DESCRIPTION`); R packages `testthat`, `roxygen2`.
* **Build / Install**: `R CMD INSTALL .` (runs `configure` -> `tools/config.R` -> writes `src/Makevars` -> `cargo build`, then `cargo run --bin document`)
* **Build tarball**: `R CMD build .`
* **Test All**: `Rscript -e 'devtools::test()'` or `Rscript -e 'testthat::test_local()'`
* **Test Target**: `Rscript -e 'testthat::test_file("tests/testthat/test-transpile.R")'`
* **Docs (roxygen)**: `Rscript -e 'roxygen2::roxygenise()'` -> updates `man/` and `NAMESPACE`
* **Rust only**: `cargo build --manifest-path src/rust/Cargo.toml`
* **Debug build**: `DEBUG=1 R CMD INSTALL .` (unoptimized Rust build, `target/debug`)
* **CRAN-style build**: `NOT_CRAN` unset and `src/rust/vendor.tar.xz` present -> offline build with `-j 2 --offline`
* **Clean**: after a release build, `R CMD INSTALL` removes `src/rust/target` via `rust_clean`; `./cleanup` removes `src/Makevars`

## Find Things
* `R/` -- exported R wrappers (`transpile.R`) and extendr-generated bindings (`extendr-wrappers.R`, **do not hand-edit**)
* `src/rust/src/lib.rs` -- Rust engine: `DIALECT_REGISTRY` (single source of truth for dialect names and aliases), `parse_dialect`, `get_dialects`, `transpile_sql`
* `src/rust/document.rs` -- generator for `R/extendr-wrappers.R`; run automatically by the build
* `src/rust/Cargo.toml` -- Rust deps and release profile (LTO, `codegen-units = 1`)
* `src/Makevars.in`, `src/Makevars.win.in` -- templates; `src/Makevars*` are generated and gitignored
* `tools/config.R` -- build-time config (reads `DEBUG`, `NOT_CRAN`, wasm target); `tools/msrv.R` -- checks Rust/Cargo presence and MSRV
* `configure`, `configure.win`, `cleanup`, `cleanup.win` -- R package build hooks
* `tests/testthat/` -- testthat suites; `tests/testthat.R` is the standard runner stub
* `man/` -- roxygen output; `NAMESPACE` -- roxygen output
* `planning/GOALS.md` -- goal list and dependency DAG (process source; read it rather than copying it here)

## Workflows
* **Changing a dialect**: edit `DIALECT_REGISTRY` in `src/rust/src/lib.rs` -> rebuild -> `sql_supported_dialects()` picks it up automatically. Do not add a parallel list in R.
* **Changing an exported Rust function**: add `#[extendr]` + roxygen comments in `lib.rs` -> `R CMD INSTALL .` regenerates `R/extendr-wrappers.R` -> `roxygenise()` updates `man/` and `NAMESPACE` -> add `export` tags on R wrappers where needed.
* **Changing an R export**: add roxygen `@export` -> `roxygenise()` -> commit `NAMESPACE` and `man/`.
* **Goals/tasks**: track in `planning/GOALS.md`; update it when a goal's status changes.
* **Release**: bump `Version` in `DESCRIPTION`; the Rust crate version lives separately in `src/rust/Cargo.toml`.

## Infrastructure
* Generated, do not commit: `src/Makevars`, `src/Makevars.win`, `src/rust/target/`, `src/rust/vendor/`, `src/rust/vendor.tar.xz` (see `.gitignore`, `src/.gitignore`).
* Offline vendoring: `src/rust/vendor-config.toml` maps crates.io to `vendor/`; the build copies it to `$CARGO_HOME/config.toml` when a vendor dir or tarball exists.
* Rust edition `2021`, `rust-version = 1.65`. Build target for webR: `wasm32-unknown-emscripten` (detected in `tools/config.R`).
* `.Rbuildignore` excludes `src/.cargo`, `src/rust/vendor`, `src/rust/target`, `src/Makevars*`, `LICENSE.md`.

## Non-Obvious System Behaviors
* `R/extendr-wrappers.R` and `src/rust/document.rs` are regenerated by the build; edits to the wrappers are overwritten.
* Dialect parsing is case-insensitive (`to_lowercase`) and aliases resolve to the same engine variant (e.g. `mssql` and `sqlserver` -> `TSQL`).
* `sql_transpile()` is vectorized in R over a character vector; `transpile_sql()` (the Rust binding) returns a vector and `sql_transpile` takes the first element, returning `NA` when empty.
* Unknown dialects raise an error containing `Unknown dialect`.

## System Boundaries & Operational Rules
### Always
* Keep `DIALECT_REGISTRY` as the only dialect list.
* Run `roxygenise()` after changing roxygen tags or exports.

### Ask First
* Changing the `polyglot-sql` version (`src/rust/Cargo.toml`) or `Cargo.lock`.
* Changing `SystemRequirements` / MSRV.
* Editing `DESCRIPTION` author/title fields (placeholders are still present).

### Never
* Hand-edit `R/extendr-wrappers.R` or anything under `src/rust/target/`.
* Commit `src/Makevars*` or vendored crate directories.
